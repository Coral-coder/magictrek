Systems

Lockstep multiplayer

Both phones run the same rules engine from the same seed. Each move carries a state digest, so the two tables can never drift apart unnoticed.

Nearby play

Host on Wi‑Fi and the other phone finds you. Or go Bluetooth with no network at all: shuttlecraft, basements, dead zones.

Subspace link

Share a six‑letter code. Moves travel encrypted through public relays, and the match picks up days later exactly where it stopped.

The full set

Every Star Trek printing plus the Commander decks and tokens, with Scryfall’s high‑resolution scans bundled in the app.

Rules engine

Combat, the stack, counterspells, Station, Sagas, Landfall, Kicker, Discover, Assimilate… every one of the 236 cards plays its printed rules.

Your rules

London or classic mulligan, free first mulligan, starting life, hand size: toggle them in Settings. The host’s rules travel with the match.

Solo & pass‑and‑play

A computer opponent that keeps games moving, auto‑saved and resumable, or two captains on one phone.

LCARS, naturally

Console beeps, haptics, a captain’s log of every event and the starfield you expect from a bridge.

Engage

  1. Install. Android: scan the code or tap the APK button, open the download, allow installs from your browser once. iPhone: scan the other code or tap the TestFlight button, install TestFlight if asked, then accept the invite. No install at all: play online in your browser below.
  2. Pick a deck. Six starter decks, one per faction, or build your own from the full set in the card database.
  3. Find your opponent. Nearby: one phone hosts, the other taps the host’s name or types the host’s IP address. Remote: share the match code; it works between the apps and the browser.
  4. Play. Tap to target, drag nothing, argue about nothing: the engine enforces the rules on both phones at once.

No install needed: the full game runs in your browser. Play the computer, take the tutorial, or create a match code and play a friend on a phone or another browser.
